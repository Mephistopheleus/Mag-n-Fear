# ОТЧЕТ О РЕАЛИЗАЦИИ ЛАБОРАТОРИИ СЦЕНАРИЕВ (ScenarioLab)

## ✅ ВЫПОЛНЕННЫЕ ИЗМЕНЕНИЯ

### 1. Интеграция ScenarioLab в main.py

#### Импорт модуля
- Добавлен импорт: `from src.scenario_lab import ScenarioLab`

#### Инициализация в TradingBot.__init__
- Создан экземпляр: `self.lab = ScenarioLab(self.config)`
- Добавлен счетчик: `self.last_lab_run = 0`

#### Запуск фонового цикла
- Добавлена задача: `asyncio.create_task(self._laboratory_loop())`

### 2. Реализация _laboratory_loop()

**Назначение:** Асинхронный фоновый цикл Лаборатории, который:
- Мониторит появление новых карточек сделок в БД
- Анализирует каждую сделку через ScenarioLab
- Подбирает оптимальные параметры (SL%, TP%, leverage, confidence)
- Сохраняет снимки оптимизации в таблицу `lab_snapshots`
- Передает результаты в AutoTuner для калибровки весов

**Параметры цикла:**
- Интервал проверки: 60 секунд
- Интервал запуска анализа: 600 секунд (10 минут) или при появлении новых карточек

**Логика работы:**
1. Подсчет карточек в SQLite (`trading_history.db`)
2. Загрузка последних 100 карточек
3. Для каждой карточки:
   - Создание псевдо-сценария с параметрами сделки
   - Вызов `lab.analyze_scenario()` для генерации вариантов улучшений
4. Генерация отчета оптимизации через `lab.generate_optimization_report()`
5. Сохранение всех снимков в таблицу `lab_snapshots`
6. Логирование лучших найденных корректировок

### 3. База данных

**Создана таблица `lab_snapshots`:**
```sql
CREATE TABLE IF NOT EXISTS lab_snapshots (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    scenario_id TEXT,
    original_pnl REAL,
    modified_pnl REAL,
    improvement REAL,
    changed_param TEXT,
    new_value REAL,
    old_value REAL,
    recommendation TEXT,
    timestamp REAL
)
```

## 🔗 ВЗАИМОСВЯЗЬ МОДУЛЕЙ

```
ShadowDealer → закрытые сделки → trading_history.db
     ↓
Laboratory Loop → загрузка карточек → анализ через ScenarioLab
     ↓
lab_snapshots ← сохранение снимков оптимизации
     ↓
AutoTuner ← использование данных для калибровки confidence_factors
```

## 📊 ЦЕЛЕВЫЕ МЕТРИКИ

Лаборатория работает на приближение к идеальным показателям:
- **100% PnL/день** — максимальная прибыль
- **100% WinRate** — все сделки прибыльные
- **0% Drawdown** — отсутствие просадок

## 🎯 ПАРАМЕТРЫ ОПТИМИЗАЦИИ

Лаборатория варьирует следующие параметры:
1. `stop_loss_pct` — процент стоп-лосса
2. `take_profit_pct` — процент тейк-профита
3. `leverage` — плечо
4. `confidence_threshold` — порог уверенности

**Метод вариации:** ±10% от базового значения (настраивается в конфиге)
